# papagaio-cli 🦜
Minimalist CLI-based spaced repetition tool I made as a pet project

## Features  
- SQLite storage (decks persist between sessions)  
- Multiple decks support 
- Simple card browser
- SM2-like scheduler with smoothly incrementing fuzz
